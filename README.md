# 购物车

这是用于 GitHub 和 Vercel 发布的 Next.js 购物车网页项目。

购物车交互、样式和图片资源位于项目根目录；`app/` 包含网页入口、页面信息和网站图标。

- `WishCart.tsx`：交互、三份清单和本地存储
- `WishCart.module.css`：手机优先的响应式样式
- `assets/ip-mascot.png`：应用 Logo 使用的个人形象图

首次运行先在仓库根目录执行 `npm install`，再执行 `npm run dev`，然后打开 `http://localhost:3000`。

部署到 Vercel 时连接此 GitHub 仓库并使用默认 Next.js 设置即可。
